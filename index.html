📁 FileMeta

Serverless File Metadata Extractor

About the Project

FileMeta is a serverless file metadata extraction system built using Amazon Web Services. When a file is uploaded to Amazon S3, AWS Lambda automatically processes the file and extracts important metadata such as file name, file type, extension, size and category. The extracted information is stored in Amazon DynamoDB.
